Cijene

Ponuda oblikovana prema vašoj infrastrukturi

Svaki Core Appliance dimenzioniramo prema modelima koje želite pokretati, potrebnom kapacitetu inferencije, hardverskom otisku i razini dostupnosti. Dobivate jednu jasnu specifikaciju proizvoda, implementacije i podrške.

01 — Ulazi u ponudu

Tri parametra oblikuju opseg.

Prvo utvrđujemo kapacitet inferencije, operativni otisak i razinu usluge koja odgovara vašem okruženju.

Dimenzioniranje
Inferencija
Modeli, kontekst, istodobni zahtjevi i očekivana propusnost određuju potreban GPU i memorijski kapacitet.
Operacije
Broj čvorova, redundancija, mrežna topologija, identitet, backup i recovery oblikuju operativni otisak.
Podrška
Dogovoreni odziv, kanali eskalacije, održavanje i zahtjevi dostupnosti definiraju razinu usluge.
02 — Opseg proizvoda

Jedna arhitektura. Tri jasna sloja.

Ponuda objedinjuje podržanu jezgru, LXC agentic runtime i povezivanje aplikacija koje već koristite.

Core Appliance
Lokalna inferencija · operativna jezgra
Podržani hardversko-softverski proizvod za privatno posluživanje modela u vašoj infrastrukturi.
  • Lokalni inference runtime i API gateway
  • Dokumentirani /models i /chat/completions endpointi
  • Console za Applications, inferenciju, hardver i postavke
  • Keycloak identitet i Application vjerodajnice
  • Activity & Audit s metapodacima korištenja
  • Observability sloj, backup i recovery
LXC agentic runtime
Agentic workflows · lokalno izvršavanje
Standardni agentic runtime u izoliranom LXC okruženju, povezan s lokalnom inferencijom i vašim postojećim workflows.
  • LXC izolacija od operativne jezgre
  • Pristup lokalnim modelima kroz podržani API
  • Agentic workflow izvršavanje u vašem perimetru
  • Jasno definirane mrežne i identitetske granice
  • Emergency Isolation Mode
  • Operativna vidljivost kroz observability sloj
Applications
Vaše aplikacije · isti workflows
Povežite omiljene aplikacije i agentic harness-e bez promjene načina na koji vaši timovi rade.
  • Application vjerodajnice po aplikaciji
  • Eksplicitne liste dopuštenih modela
  • Streaming i non-streaming Chat Completions
  • Tool-call transport za postojeće workflows
  • Vaše klijentske aplikacije i workflowi ostaju isti
  • Metapodaci korištenja bez sadržaja zahtjeva
  • Samostalna rotacija i opoziv pristupa

06 — FAQ

Pitanja o ponudi.

Kako se proizvod dimenzionira, što uključuje i kako se uklapa u vašu postojeću infrastrukturu.

Kako se oblikuje ponuda?

Ponuda se oblikuje prema modelima koje želite pokretati, potrebnom kapacitetu inferencije, hardverskom otisku, razini dostupnosti i opsegu podrške.

Što uključuje Core Appliance?

Core Appliance uključuje lokalnu inferenciju, dokumentirani API, operativni Console, identitet, Activity & Audit, observability sloj, LXC agentic runtime te potpisani životni ciklus ažuriranja, backupa i oporavka.

Je li LXC agentic runtime dio ponude?

Da. LXC agentic runtime dio je standardne arhitekture za agentic workflows uz lokalnu inferenciju.

Možemo li povezati postojeće aplikacije?

Da. Povežite omiljene aplikacije i agentic harness-e putem dokumentiranih /models i /chat/completions endpointa. Vaše aplikacije i workflows ostaju isti.

Gdje se appliance implementira?

Appliance se implementira u infrastrukturi klijenta, pod klijentovom kontrolom identiteta, mreže i operacija.

Što najviše utječe na opseg ponude?

Najveće varijable su veličina i broj lokalnih modela, očekivana istodobnost, zahtjevi dostupnosti, hardverska redundancija i opseg operativne podrške.
