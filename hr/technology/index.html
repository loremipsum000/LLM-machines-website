03 · FAQ

Pitanja o arhitekturi.

Detalji koje sigurnosni, platformski i developer timovi obično pitaju prije odobravanja on-prem AI implementacije.

Mogu li postojeći API klijenti koristiti LLM Machines?

Da. Postojeći klijenti mogu se povezati kroz dokumentirani Chat Completions protokol, dok /models endpoint prikazuje skup odobrenih modela.

Može li appliance raditi bez pristupa javnom internetu?

Da. Potpisani offline entitlement i lokalni registri modela podržavaju izolirani rad unutar vaše infrastrukture.

Koji se modeli mogu pokretati lokalno?

Arhitektura je dizajnirana za open-weight familije modela kao što su Llama, Mistral i Qwen, s izborom modela dimenzioniranim prema vašim zahtjevima za hardver, latenciju i kvalitetu.

Kako se upravlja Application vjerodajnicama?

Svaka Application dobiva vlastiti statički ključ ili OAuth client credentials, zasebne modele i lokalno upravljanje rotacijom i opozivom.

Kako LXC runtime podržava napredne integracije?

LXC runtime pruža sekundarnu granicu izvođenja za zasebno ugovorene napredne integracije, uključujući agentic primjene. S odobrenim modelima povezuje se kroz dokumentirani inferencijski API.

Što čini upravljanu inferencijsku jezgru?

Upravljana inferencijska jezgra obuhvaća infrastrukturnu platformu, lokalni inference runtime, gateway i pravila, operativni Console, identitet, Observability sloj te lifecycle i recovery kontrole.
