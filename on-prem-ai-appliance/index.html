On-prem AI appliance

Local Inference, Ready for Your Enterprise

LLM Machines brings local model serving, a compact operational Console, an observability layer and an LXC agentic runtime into your infrastructure. Connect your favourite apps and harnesses. Nothing leaves your infrastructure.

01 — Appliance

Hardware, software and runbook together.

An appliance should be more than a GPU server. It should arrive as an operated AI stack with support boundaries, identity integration and production controls.

Inference

Local model serving.

Run open-weight models on hardware sized to your latency, quality and throughput requirements.

Supported API

Familiar endpoints.

Use /models and streaming or non-streaming /chat/completions, including tool-call message transport.

Applications

Connect your favourite apps.

Issue local Application credentials, set model access and keep the client workflows your teams already use.

Agentic runtime

LXC agentic workflows.

Run agentic workflows in a dedicated local LXC runtime connected to the supported inference contract.

Operations

Local observability layer.

Monitor model health, capacity, usage metadata, alerts and hardware from inside the appliance.

Resilience

Emergency Isolation Mode.

Protect the inference boundary while operational Console, identity, audit, backup and recovery remain available.

02 — Deployment

Designed for customer-controlled infrastructure.

The appliance runs on your premises, including isolated environments with signed offline entitlements and local model registries.

For IT and security teams.

Identity federation, Admin and Operator roles, network pre-flight, metadata-only audit and signed lifecycle controls are handled during onboarding.

  • OIDC / SAML identity federation
  • Signed offline entitlement
  • Local Application credentials

For business teams.

LLM Machines provides local inference and a documented API contract. Your client applications and workflows stay the same.

  • Favourite apps and harnesses
  • Local agentic workflows
  • Customer-controlled operations
